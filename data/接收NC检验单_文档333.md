- **方法**: `POST`
- **完整路径**: `http://192.168.17.128:25710/api-prj/openapi/security/token`

### Headers

| Key | Value | 备注 |
|-----|-------|------|
| `Content-Type` | application/json |  |

### Body (raw)

```json
{
  "appId": false,
  "appSecret": "67ZwYAzTpzVUHJBME2WSXmV6qvZT4ZWS"
}
```
